# Da Paz Confeitaria

Site comercial para apresentação de uma confeitaria e seus produtos.

## Recursos identificados
- Apresentação de produtos
- Identidade visual personalizada
- Layout responsivo
- Tipografia personalizada
- Estrutura orientada a catálogo/apresentação comercial

## Tecnologias identificadas
- HTML
- CSS
- JavaScript
- Fraunces
- Manrope

## Objetivo
Criar uma presença digital profissional para um negócio de confeitaria.
